# Dev Keyboard

Fcitx5 addon (c++) to define hotkeys for various developer-related text transformations.

## MVP Functionality
- Sha256
- Base64
- Cases (camelCase, TitleCase, snake_case, CAPITAL_SNAKE_CASE)

## Future Functionality
- Numeric base conversion
- Configurable hotkeys

## Tech Stack
- C++ (built with CMake)
- [Fcitx](https://wiki.archlinux.org/title/Fcitx) input method framework
- [OpenSSL](https://openssl-library.org/) cryptography library
